📡 Fuentes de datos

USGS Earthquakes — Terremotos en tiempo real vía earthquake.usgs.gov (servicio geológico de EE.UU., datos globales)

NASA FIRMS — Incendios activos detectados por satélite MODIS/VIIRS vía firms.modaps.eosdis.nasa.gov

AEMET — Alertas meteorológicas de la Agencia Estatal de Meteorología (requiere API key)

OpenAQ — Calidad del aire en ciudades españolas vía openaq.org (datos abiertos)

Copernicus EMS — Inundaciones e incendios vía emergency.copernicus.eu (programa UE)

⚙️ Metodología

NearMe OSINT es un motor de agregación geográfica OSINT. Cada fuente de datos se normaliza a un modelo único de evento geolocalizado con: tipo, nivel, coordenadas, radio de afectación y descripción.

Los recolectores Python se ejecutan cada 15 minutos vía cron. Los eventos se almacenan en PostgreSQL + PostGIS y se sirven a través de una API REST (FastAPI).

La consulta geoespacial responde a la pregunta: "¿Qué eventos hay a menos de X km de esta ubicación?" usando la función ST_DWithin de PostGIS con índice espacial.

ℹ️ Sobre NearMe OSINT

Proyecto de agregación de datos públicos geolocalizados. Convierte APIs, RSS y fuentes abiertas en un flujo único de eventos con coordenadas.

No es un dashboard temático. Es un "Google Maps de los eventos públicos". Cualquier dato público con coordenadas termina en el mismo sistema, independientemente de la fuente.
